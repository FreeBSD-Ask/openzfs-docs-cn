1. 动手前完整阅读 `AGENTS.md` 与 `shu-yu-biao.md`，术语一律以术语表为准。

3. 逐处 Edit 修改，禁止 sed/awk/python 批量替换；每处修改前确认属实，修改后复核。

6. 改完对改动文件运行 `markdownlint-cli2 "<文件>" --config .github/.markdownlint.json`，保持全仓 0 错误（无序列表用 `*`）。
7. 修改明细写入 `script/proofread-logs/<批次名>.md`（不跟踪）；日志应**边改边写**，防止代理中断丢失记录。
