# zfs-project(8)

## 名称

`zfs-project` — 管理 ZFS 文件系统中的项目

## 概述

```sh
zfs project [-d|-r] 文件|目录…
```

```sh
zfs project -C [-kr] 文件|目录…
```

```sh
zfs project -c [-0] [-d|-r] [-p id] 文件|目录…
```

```sh
zfs project [-p id] [-rs] 文件|目录…
```

## 说明

### `zfs project [-d|-r] file|directory …`

列出文件和目录的项目标识符（ID）与继承标志。

#### `-d`

显示目录自身的项目 ID 和继承标志，而不显示其子项的。

#### `-r`

递归列出子目录。

### `zfs project -C [-kr] file|directory …`

清除文件和目录上的项目继承标志和/或项目 ID。

#### `-k`

保持项目 ID 不变。若未指定，项目 ID 将重置为零。

#### `-r`

递归清除子目录的标志。

### `zfs project -c [-0] [-d|-r] [-p id] file|directory …`

检查文件和目录上的项目 ID 与继承标志，报告没有项目继承标志、或项目 ID 与目标目录的项目 ID 或 `-p` 指定的 ID 不一致的条目。

#### `-0`

用 NUL 字节而不是换行符分隔文件名，且不输出诊断信息。

#### `-d`

检查目录自身的项目 ID 和继承标志，而不检查其子项的。

#### `-p id`

与 `id` 比较，而不是与目标文件和目录各自的项目 ID 比较。

#### `-r`

递归检查子目录。

### `zfs project [-p id] [-rs] file|directory …`

在文件和目录上设置项目 ID 和/或继承标志。

#### `-p id`

将项目 ID 设为给定值。

#### `-r`

递归应用到子目录。

#### `-s`

在给定的文件和目录上设置项目继承标志。这通常与 `-r` 配合使用来设置目录树配额。此时，除非用 `-p` 显式指定，目录的项目 ID 会设置给它的所有后代。
