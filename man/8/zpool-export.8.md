# zpool-export(8)

## 名称

`zpool-export` — 导出 ZFS 存储池

## 概述

```sh
zpool export [-f] [-a | 池名…]
```

## 说明

将给定池从系统中导出。所有设备都会被标记为已导出，但仍被其他子系统视为正在使用。只要存在足够数量的设备，这些设备就可以在系统之间移动（包括字节序不同的系统）并导入。

导出池之前，池内的所有数据集都会被卸载。如果池有一个正在使用中的共享热备盘，则该池无法导出。

要让池具备可移植性，必须给 `zpool` 命令提供整块磁盘而非仅仅分区，这样 ZFS 才能用可移植的 EFI 标签为磁盘打标签；否则，字节序不同的平台上的磁盘驱动器将无法识别这些磁盘。

### `-a`

导出系统上所有已导入的池。

### `-f`

强制卸载所有数据集，并允许导出带活动共享热备盘的池。

此命令即使池的共享热备盘正在使用中也会强制导出。这可能导致数据损坏。

## 示例

### 示例 1：导出 ZFS 存储池

以下命令导出池 `tank` 中的设备，以便移动位置或稍后导入：

```sh
# zpool export tank
```
