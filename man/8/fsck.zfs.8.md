# fsck.zfs(8)

## 名称

`fsck.zfs` — 占位用 ZFS 文件系统检查器

## 概述

```sh
fsck.zfs [选项] 数据集…
```

## 说明

`fsck.zfs` 是一个轻量的 shell 包装器，至多检查数据集所在池的状态。OpenZFS 之所以安装它，是因为某些 Linux 发行版要求所有文件系统都提供配套的 fsck 辅助程序。

如果指定了多个数据集，将依次逐一检查，并把结果按位或合并。

## 选项

所有选项均被忽略。

## 注意

检查 ZFS 数据集的方法是在其所在的池上运行 `zpool scrub`。单个 ZFS 数据集永远不会脱离其所在的池被独立检查，这一点与常规文件系统不同。

不过，fsck(8) 接口仍然允许它传达一些错误信息：如果数据集位于降级的池中，`fsck.zfs` 将返回退出码 `4`，表示存在未修正的文件系统错误。

类似地，如果数据集位于故障池中，并且在 `/etc/fstab` 中有一条旧式记录，`fsck.zfs` 将返回退出码 `8`，表示发生了致命的操作错误。
