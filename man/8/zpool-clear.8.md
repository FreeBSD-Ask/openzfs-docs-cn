# zpool-clear(8)

## 名称

`zpool-clear` — 清除 ZFS 存储池中的设备错误

## 概述

```sh
zpool clear [--power] 池名 [设备…]
```

## 说明

清除池中的设备错误。未指定参数时，清除池内的所有设备错误；指定一个或多个设备时，只清除与这些设备关联的错误。

如果池曾被挂起，只要设备可以访问，就会把它恢复上线。启用了 `multihost` 的池在被挂起后，若有证据表明该池曾被另一台主机导入，则无法恢复。清除操作开始前，会执行与导入时相同的检查。

### `--power`

为存储机箱中该设备的插槽通电，并等待设备出现后再尝试清除错误。这会对所有指定的设备执行。也可以设置 `ZPOOL_AUTO_POWER_ON_SLOT` 环境变量以始终启用此行为。注意：该选项目前仅在 Linux 上有效。
