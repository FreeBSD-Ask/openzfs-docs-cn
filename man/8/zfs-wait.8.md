# zfs-wait(8)

## 名称

`zfs-wait` — 等待 ZFS 文件系统中的活动停止

## 概述

```sh
zfs wait [-t 活动[,活动]…] 文件系统
```

## 说明

等待指定文件系统中给定类型的所有后台活动停止。活动停止可能是因为它已经完成，也可能是因为文件系统已被销毁或卸载。如果未指定任何活动，该命令会等待下列列出的每一种类型的后台活动都停止。如果给定类型当前没有正在进行的活动，该命令会立即返回。

以下是 `activity` 的可能取值，以及各自等待的内容：

### `deleteq`

文件系统的内部删除队列清空

注意，内部删除队列要等到所有大文件都有时间被完全销毁、并且所有指向已取消链接文件的打开文件句柄都关闭之后，才会完成清空。
