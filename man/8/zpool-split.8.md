# zpool-split(8)

## 名称

`zpool-split` — 从 ZFS 存储池中拆分出设备，创建新池

## 概述

```sh
zpool split [-gLlnP] [-o 属性=值]… [-R 根目录] 池名 新池名 [设备…]
```

## 说明

从池中拆分出设备以创建新池。池中的所有 vdev 必须都是镜像，且池不能正在执行 resilver。拆分时，新池将是原池的一个副本。默认情况下，每个镜像中的最后一个设备会从原池中拆出，用于创建新池。

可选的设备指定会使指定设备被纳入新池；如果有设备未指定，则按默认方式使用每个镜像中的最后一个设备。

新池会获得新的 GUID。在 Linux 上，新池的文件系统因此在首次挂载时会获得新的文件系统 UUID；参见 zfsprops(7) 中的 `guid` 属性，以及 zpool-reguid(8) 的“文件系统 UUID 与 overlayfs”一节中所述其对 overlayfs 的影响。

### `-g`

显示 vdev 的 GUID，而不是通常的设备名。这些 GUID 可以在 zpool 的 detach/offline/remove/replace 命令中代替设备名使用。

### `-L`

显示 vdev 的真实路径，解析所有符号链接。无论打开设备时使用的 `/dev/disk/` 路径是什么，都可以用它查找当前的块设备名。

### `-l`

表示此命令在使新池上线时，会为其尝试挂载的所有加密数据集请求加密密钥。注意，如果任何数据集的 `keylocation` 为 `prompt`，此命令将阻塞，等待输入密钥。不使用此标志时，在加载密钥之前，加密数据集将一直不可用。

### `-n`

执行一次试运行（“no-op”）性质的拆分：并不真正执行，而是打印新池的预期配置。

### `-P`

显示 vdev 的完整路径，而不只是路径的最后一个组成部分。此选项可以与 `-L` 标志配合使用。

### `-o property=value`

为新池设置指定的属性。有关可用池属性的更多信息，参见 zpoolprops(7) 手册页。

### `-R root`

把新池的 `altroot` 属性设为 `root`，并自动导入它。
