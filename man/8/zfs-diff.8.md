# zfs-diff(8)

## 名称

`zfs-diff` — 显示两个 ZFS 快照之间的差异

## 概述

```sh
zfs diff [-FHth] 快照 快照 | 文件系统
```

## 说明

显示给定文件系统的某个快照与该文件系统之后某个快照（或文件系统当前内容）之间的差异。第一列是一个指示变更类型的字符，其余各列分别指示路径名、新路径名（重命名时）、链接计数变化，以及可选的文件类型和/或变更时间。变更类型如下：

### `-`

该路径已被移除

### `+`

该路径已被创建

### `M`

该路径已被修改

### `R`

该路径已被重命名

### `-F`

以与 ls(1) 的 `-F` 选项相似的方式显示文件类型指示。

* `B`：块设备
* `C`：字符设备
* `/`：目录
* `>`：门
* `|`：命名管道
* `@`：符号链接
* `P`：事件端口
* `=`：套接字
* `F`：常规文件

### `-H`

提供更具可解析性的制表符分隔输出，不带标题行，也不带箭头。

### `-t`

在输出的第一列显示该路径的 inode 变更时间。

### `-h`

不对非 ASCII 路径进行 `\e0ooo` 转义。

## 示例

### 示例 1：显示快照与 ZFS 数据集之间的差异

以下示例展示了如何查看 ZFS 数据集的先前快照与其当前状态之间发生了哪些变化。使用 `-F` 选项显示受影响文件的类型信息。

```sh
# zfs diff -F tank/test@before tank/test
M       /       /tank/test/
M       F       /tank/test/linked      (+1)
R       F       /tank/test/oldname -> /tank/test/newname
-       F       /tank/test/deleted
+       F       /tank/test/created
M       F       /tank/test/modified
```
